# CortexView explainer: timed production script

Total length is **90.0 s** (six segments, set in `animation/config.py`). The narration is **208 words**, the same text as `voiceover_clean.txt`.
Durations below assume a calm read of about **150 words per minute** (≈2.5 words/s). Beat times are the `BEATS` in `config.py`. Change both together.

Notation (production only, not to be spoken): `/` = short pause (~0.3 s), `//` = longer pause (~0.7 s), **bold** = light emphasis.

Every image on screen is the **synthetic phantom** from the CortexView web prototype, reproduced exactly in Python (`animation/phantom.py`, verified against `frontend/src/cortexview/demo/phantom.ts`). Every number is computed from its pixels: lesion = 2,211 px × (0.56 mm)² ≈ 693 mm², largest boundary distance ≈ 32.8 mm.

Accuracy: these are exactly the prototype's formulas (`buildPhantomSlice()` in `phantom.ts`): `mm2 = n·SP²` and `diam = max distance between lesion boundary pixels × SP`, with SP = 0.56 mm/px.
